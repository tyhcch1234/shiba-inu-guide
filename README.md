# 柴犬手帖 · Shiba Inu Field Notes

一個關於柴犬嘅單頁網站：品種起源、外觀特徵、性格、生活習慣、飲食喜好、日常照顧與健康須知。

## 內容結構

| 區塊 | 內容 |
| --- | --- |
| 品種小檔案 | 原產地、分類、體高、體重、壽命、毛色、運動量 |
| 起源 | 由山地獵犬到家庭伴侶犬的時間軸 |
| 外觀 | 三角耳、杏仁眼、捲尾、裏白、雙層毛 |
| 性格 | 忠誠、獨立、警覺、愛乾淨、對陌生人保留、固執 |
| 生活習慣 | 一日作息、換毛、怕熱、逃脫本能 |
| 飲食 | 喜歡的食物、絕對禁忌清單、餵食原則 |
| 照顧 | 每日／每週／每月清單、訓練、社會化、夏季護理 |
| 健康 | 常見遺傳問題、疫苗驅蟲、求醫警號 |
| FAQ | 公寓、訓練難度、小朋友、剃毛、食量 |

## 技術

- 純靜態：`index.html` + `style.css` + `script.js`，無框架、無建置步驟
- 響應式版面（桌面／平板／手機）
- 原生 IntersectionObserver 進場動畫與導覽 scrollspy
- 照顧清單以 `localStorage` 記錄打勾狀態
- 字體：Noto Serif TC / Noto Sans TC（Google Fonts，載入失敗時回退系統字體）

## 本機預覽

直接開啟 `index.html` 即可，或：

```bash
python3 -m http.server 8000
```
